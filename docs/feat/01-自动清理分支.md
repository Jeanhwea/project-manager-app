# 自动清理分支命令需求文档

## 概述

1. 重写 `pma br cl`（`pma branch clean`）命令，
   - 将之前"只保留 master/dev 及其别名、其余全删"的粗暴逻辑改为**基于分支分类的精细化清理**
   - 让开发者在日常清理时能安全操作，只删除那些已经没有保留价值的分支。
2. `pma br cl` 命令太长，简化敲  `pma c` 实现相同功能


## 分支分类体系

| 类别     | 定义                                           | 清理策略                 | 英文标识  |
|----------|------------------------------------------------|--------------------------|-----------|
| **A 类** | 保护分支（`master`、`main`、`develop`、`dev`） | 永不删除                 | Protected |
| **B 类** | 未合并到任一保护分支的分支                     | 默认保留，加 `-D` 时清理 | Unmerged  |
| **C 类** | 已合并到 `master` 或 `dev` 的非保护分支        | 始终清理                 | Merged    |
| **D 类** | 远端孤儿分支（本地没有跟踪分支的远端分支）     | 始终清理                 | Orphan    |

### A 类 — 保护分支

- 定义：`master`、`main`、`develop`、`dev`
- 行为：无论传入什么参数都不会被删除
- 保护手段：在 `collect` 阶段直接过滤，不进入待删除列表
- 对应远端同名分支同样不删除

### B 类 — 未合并分支

- 定义：所有非保护、非当前分支中，未合并到 `master` 或 `dev` 的分支
- 判定方式：执行 `git branch --merged master` 和 `git branch --merged dev`，取并集作为已合并列表；不在该列表中的即为 B 类
- 默认行为：**跳过**，仅打印提示信息
- `-D` 行为：同时将 B 类分支加入删除列表
- 远端同名分支：同步清除

### C 类 — 已合并分支

- 定义：所有非保护、非当前分支中，已合并到 `master` 或 `dev` 的分支
- 判定方式：与 B 类相反——在已合并列表中的即 C 类
- 行为：**始终删除**，不受 `-D` 影响
- 远端同名分支：同步清除

### D 类 — 远端孤儿分支

- 定义：远端存在但本地没有对应跟踪分支的远端分支
- 行为：始终删除
- 注意：D 类分支没有本地分支，因此只删除远端
