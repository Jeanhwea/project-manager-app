* Branch Clean 命令需求文档

**概述**: 重写 `pma br cl` (Branch Clean) 命令的分类清理逻辑。

**分支分类**:
- A类（保护分支）: master, main, develop, dev —— 永不删除
- B类（未合并分支）: 未合并到 A 类分支的分支 —— 默认保留，加 -D 时清理
- C类（其他分支）: 既不属于 A 类也不属于 B 类的分支 —— 始终清理

**逻辑**:
1. 收集所有本地分支
2. 标记 A 类分支（保护分支）
3. 检查每个非 A 类分支是否已合并到 master 或 dev（使用 `git branch --merged`）
4. 已合并的分支 → C 类，始终清理
5. 未合并的分支 → B 类，仅当加了 -D 时才清理
6. 远端同名分支同步清理
7. 远端孤儿分支（本地无跟踪的远端分支）始终清理

**参数变更**:
- 新增 `-D` / `--delete-unmerged` 参数，用于同时清理 B 类分支
- 保留 `--dry-run` / `-n` 和 `--remote` 参数

**远端分支处理**:
- 删除本地 C 类/B 类分支时，同步删除远端同名分支
- 远端孤儿分支（本地无跟踪的远端分支）始终清理

**安全保护**:
- 必须保留当前分支，即使它属于 B 类
- 必须保留 A 类分支，即使显式传入
- 默认行为（不带 -D）只删除安全的 C 类分支

**输出信息**:
显示本次清理的分支分类统计，例如:
  - C类分支: feature-1, feature-2
  - B类分支: (跳过，使用 -D 可清理)
  - D类孤儿分支: origin/stale-branch
